  (`ver=975b115efeb8`) and the three Divi stylesheets the page loads were
  fetched once (browser UA, 2 s apart). A local sim serves that live page with

  CSS/JS. "After" = this branch's fragment (`/embed/fpa`) spliced into the same
  page, CSS/JS same-origin. The WP proxy is simulated same-origin.
- The asset host is simulated as its own host name; "blocked" maps it to

- Phone widths via CDP `Emulation.setDeviceMetricsOverride` (true 390px, not
  Chromium's 500px window floor). Hit areas measured with
  `document.elementFromPoint` along each target's center lines, so padding,
  negative margins and overlaps count the way a finger does; also the plain
  bounding box.
- The live page carries a WordPress-side inline patch, `<style
  id="sc28-a11y">` (not in this repo): `a.scf-cell-link,a.scf-team-link

## Item 3: filters and archive navigation (WEB-020 / WEB-025)

### Found

- Both routes printed `href="/nfl/fantasy-points-allowed-by-position/?format=half"`,
  `?format=standard` and `?view=adjusted` (nofollow). On `/2025/` those three
  pointed at the CURRENT season's page.
- The bundle's swap sent only `format` and `view` to
  `/wp-json/statchasers/v1/p/embed/fpa`, whose default is the current season:
  on `/2025/` a Half-PPR click painted the 2026 table under the 2025 heading.
- The current page had no link to `/2025/` (the archive list was removed from
  the live page 2026-11-04); the archive was reachable only via the sitemap.
  The archive's "Current 2026 data" link existed.

### Changed

- Scoring and view controls are `<button type="button" aria-pressed>` in a
  `role="group"` named Scoring / View (`fpa-render.ts`). No href. Same visual
  pills. Root carries `data-default-format`.
- `client/fpa.ts` (pattern aligned with the SOS branch bb891ea0): the choice
  goes in the fragment, `#format=half&view=adjusted` (defaults omitted), via
  `pushState`; `popstate` + `hashchange` re-sync; a shared fragment is fetched
  on load; an old `?format=&view=` bookmark is server-rendered as before and
  rewritten in place to the fragment form (`replaceState`). The path is never
  touched, so `/2025/` stays `/2025/`. Archive swaps send `season`; a response
  for another season is refused. Latest click wins (token), focus returns to
  the pressed pill, failed fetch falls back to the old query URL (server
  renders it). The live page sends no `season`, so its proxy cache keys are
  unchanged; the proxy keys on the full sorted query, so no key consolidation
  was needed or done.
- The live page links its archive again with an ordinary `<a href>` under the
  table ("Archive: 2025 full season"). Visible change: needs mak's OK (it
  reverses part of the 11-04 removal, moved under the table).
- OFF header ships `aria-sort="descending"` (rows arrive in OFF order); the
  sort toggles from the header's current state.

### Behavior evidence (Chromium, sim, 390px) - 22/22, and 22/22 with the asset host blocked

Fixture: real data where PPR and Standard differ in value and order (PPR first
row TEN 23.9, order TEN,LV,DAL,NE,ARI; Standard LV 21.2, order LV,TEN,DAL,ARI,NE).

- Standard click: table value and row order equal the server's Standard
  render; address `.../cur#format=standard`; `aria-pressed` moved.
- Reload keeps Standard. Half, then Back -> Standard, Forward -> Half.
- Rapid Standard -> PPR (5 ms) -> aFPA (400 ms): ends on PPR adjusted, data
  matches the server, `#view=adjusted`, no stuck `aria-busy`.

  rewritten to `#format=standard&view=adjusted`. Shared `#format=half` opens Half.
- `/2025/`: Standard click stays 2025 and equals the server's 2025 Standard;
  bookmark `/2025/?format=half&view=adjusted` opens 2025 Half adjusted; Back
  across documents restores the right table; endpoint failure falls back to
  `/2025/?view=adjusted`, server-rendered, still 2025.
- 2025 data supports all six combinations (all 200).

## Item 4: mobile (WEB-049 / WEB-050 / WEB-023)

### Small targets (< 24 x 24 hit area), 390px

| | targets | under 24 | by kind |
|---|---|---|---|
| before, fpa.css alone (no sc28 patch) | 229 | **202** | sort headers 6/6 (box 14x12), team links 32/32 (44x22), cell links 160/160 (53x19), FAQ questions 4/19 (21px tall) |

| before, asset host blocked | 223 | 204 | no stylesheet, no sort |
| after, either route, with or without the patch, host reachable or blocked, 390 / 768 / 1280 | 211-231 | **0** | - |

Fixes in `fpa.css`, density kept (data rows unchanged at 29px):
cell links `min-height:24px` border-box (fills the cell already taller than
24); team link `min-height:24px` (crest is 22); sort button fills its header
cell via negative margins (band ~23 -> 24px); FAQ summary borrows 5px of the
row's own padding each way (no movement); season link inline-flex 24px. The
pills (now buttons) keep 30px. Button reset at `.scf-opt` weight, plus a host
override for Divi's `button:hover {padding:.3em 1em; background}` (0,1,1),
which would have resized hovered pills and un-navied the pressed one; pill
side padding is a token (`--scf-opt-pad-x`) so the narrow tiers still apply.
Focus ring on pills, sort headers (soft gold on navy), team and season
links; pressed state has a forced-colors ring; sort arrow given empty alt text
(`content: " ↓" / ""`), direction via `aria-sort`.

The sc28 WordPress patch becomes redundant once this ships; it is harmless
(it turns cell links inline-flex, still 24px).

### Document width

### Contrast (WCAG AA, computed on the real stylesheets)

Every text node in the tool at 390 and 1280, both routes, foreground vs the
composited background. One failure, before and after the other changes:

- TE rail card title `#a87905` on white, 11-12px: 3.89:1. Fixed: text uses
  `#80600f` (5.84:1, the site's own tag-link gold); the card edge keeps the
  brand gold.

All else passed. Remaining: the hovered card title (`--sc-gold-deep`, 3.89:1,
transient state) left as is.

Color alone: the tier tint is the only VISIBLE difficulty cue in a cell. The
rank is visually hidden by design (mak, 2026-10-08) but stays in the
accessibility tree, the cell `title` names the tier in words, and the legend
names each tint. A visible non-color cue for sighted colorblind readers needs
mak's call (e.g. a small rank or a mark on the extreme tiers). Not changed.

### Same-origin assets (WEB-023)

`statchasers_fpa_asset_urls()` in `statchasers-local-assets.php` (same
lockstep rule as the team depth chart: bundled copy only when it is the API's
current build or byte-identical to the live one, else the asset host);

WP Rocket CSS exclusions cover `/assets/api/fpa.css`; the bundle keeps
defer + nowprocket via the existing `/dist/statchasers-` rule.
`build-zip.sh` copies and verifies (sha256 = manifest) both files:

    statchasers-news/assets/api/fpa.css               18,043 B
    statchasers-news/assets/api/dist/statchasers-fpa.js 6,056 B
    statchasers-news/assets/api/manifest.json (names all four files)

This aligns with `fix/sos-web023-assets-2026-11-27` (same function shape and
`statchasers_local_asset_stylesheets()`); the two branches will conflict on the
same lines of `statchasers-local-assets.php`, `build-zip.sh` and
