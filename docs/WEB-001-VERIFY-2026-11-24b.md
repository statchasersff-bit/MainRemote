## Gaps found and fixed

1. **lastmod** (040e4cf). c1948cd sent `modified: null` (no lastmod). Now
   `modified` = newer of:
   - the box score's `modifiedAt`: buildBoxscores.mjs keeps the stored value when a
     re-pull brings an identical (trimmed) summary and sets now only when it differs.
     Legacy records (no field) use `fetchedAt` when it was an in-season pull
     (within 30 days of kickoff: all 163 of 2026); the 2021-2025 archive was pulled in
     one bulk run on 2026-09-30, so those 1,424 games print no lastmod.
   - the written recap's `writtenAt` (recap_prose_<season>.json); writeRecaps.mjs now
     keeps it when an import brings back the same headline and paragraphs.
   Never the kickoff. Play-by-play, videos and odds keep no per-game stamp and do not
   move it. The plugin needed no change (it already prints a non-null `modified`).
2. **Series page title/H1** (42d6a1d). The pair URL still wore its latest game's
   title ("Rams vs Cardinals Player Stats, Box Score & Highlights | 2026") and H1
   ("... Match Player Stats"): mak's 10-09/10-30 wording, from before games had their
   own pages. The brief asks for a series-specific title and H1. Now: the existing
   head-to-head ladder ("Arizona Cardinals vs Los Angeles Rams: Head-to-Head History"),
   the series description, H1 "{A} vs {B} Head-to-Head Series", no single-game
   "match player stats" intro. The latest result and its "Full box score" link stay.
   Upcoming preview untouched. **This reverses an approved SEO wording; it is a
   separate commit so it can be dropped if mak prefers.**
3. **Sitemap refresh behind Rank Math's cache** (8f5b274). Rank Math calls the
   provider only on a cache miss and never expires the `game` files on its own;
   a post save clears only the post type + index. So a newly final game or a
   corrected lastmod could wait indefinitely. The plugin now runs
   `statchasers_matchup_games()` at `init` on /sitemap_index.xml and
   /game-sitemap*.xml; its existing row diff invalidates Rank Math's `game` + index.
