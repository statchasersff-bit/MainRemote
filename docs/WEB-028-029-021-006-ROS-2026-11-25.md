## Repository changes

- `statchasers-legacy-routes.php` (new): plugin-side 301s from both legacy
  rankings paths to the overall ROS hub (404-only, exact, priority 1 ahead of
  `redirect_canonical`), so deleting either upstream rule cannot fall through
  to WordPress's slug guesser. Page 5831 `/fantasy-football/` 301s to the
  existing hub `/nfl/fantasy-football-tools/`; the breadcrumb crumb at
  `/fantasy-football/` now names and links that hub; `/fantasy-football/`
  leaves the Rank Math sitemap. Tests: `tests/smoke-legacy-routes.php`.
- `statchasers-page-identity.php`: a `ros` family on the WEB-021 pattern
  (Organization `/#organization`, WebSite `/#website`, per-route WebPage with
  the FAQ merged into it, brand card og:image + primaryImageOfPage, position
  pages get their own last crumb). Tests: ROS routes in `smoke-page-identity.php`.
- API (WEB-029): ROS board line says what the ranks measure and links weekly
  projections; player Outlook "Best fit" note links the position ROS page when
  it quotes a ROS rank; Redraft Command and SOS projection links say weekly /
  rest-of-season accurately. The rankings, the source date and the stale-rank
  safeguard are untouched.
