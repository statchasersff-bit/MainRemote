# WEB-036: reproducible career fantasy totals (2026-11-26)

Branch `pa1126/i2`, base main 4cb49ac. Scoring under the deployed setting `SC_SCORING_TOTALS=house`
(house rule, full PPR, -1 per interception, -2 per fumble lost, 2 per two-point conversion, 6 per
return/fumble-recovery TD). No house coefficient changed.

## Finding: the 316.2 is correct; the missing 4.3 is a touchdown pass

Amon-Ra St. Brown's 2024 career row is summed from his 17 weekly game-log entries
(`data/player/game_logs/2024.json`, player 7547) by `careerSeasonTotals()` (metrics.ts), each week scored by
`getFantasyPoints()` (house rule). The season's stat sums:

| Field | 2024 sum |
|---|---|
| rec / rec_yd / rec_td | 115 / 1,263 / 12 |
| rush_att / rush_yd / rush_td | 2 / 6 / 0 |
| fum / fum_lost | 1 / 1 (Week 15 at BUF) |
| pass_att / pass_cmp / pass_yd / pass_td / pass_int | 1 / 1 / 7 / 1 / 0 (Week 4 vs SEA) |
| 2-pt, return TD, fumble-recovery TD | none |

Component arithmetic:

```
Receptions     115 x 1      = 115.00
Receiving yds  1,263 x 0.1  = 126.30
Receiving TD   12 x 6       =  72.00
Rushing yds    6 x 0.1      =   0.60
Fumbles lost   1 x -2       =  -2.00
                visible sum = 311.90
Passing yds    7 x 0.04     =   0.28   (no column on a WR row)
Passing TD     1 x 4        =   4.00   (no column on a WR row)
                      total = 316.18 -> 316.2
```

The 4.28 is a real event, not a coincidence: Week 4 2024 (MNF vs Seattle) St. Brown threw a 7-yard
touchdown to Jared Goff. Goff's own 2024 log carries the mirror line (1 rec, 7 yds, 1 rec TD), which was
equally invisible on his QB row (no receiving columns). Checked and ruled out: two-point conversions (none),
return scoring (none), fumble treatment (one fumble, lost, -2 under the house rule; the provider's extra -1
per fumble does not apply under `house`).

Root cause: the scoring was right; the career table had no column for scoring outside the position's
column set, so the printed figures could not reproduce the total.

## What changed

- `src/lib/player/metrics.ts` `careerSeasonTotals()`: each season now also returns `two_pt`, `other_td`
  (kick/punt return + fumble-recovery TD), `kick_fgm`, `kick_xpm`, `kick_pts` (house-rule kicking points)
  and `unmodeled` (points in the total the stat line does not record; 0 under `house` except a kicker
  week with no field-goal distances, which keeps the provider total). Types in `types.ts`.
- `src/lib/player/stats-profile.ts`: `CareerStatRow.scoring`, `careerScoringExtras(row, position, format)`
  and `scoringExtraText()`. Extras are computed from the row's own counts with `HOUSE_RULES`: passing for a
  non-QB, receiving for a QB, 2-pt conversions, return/fumble-recovery TD, kicking, and the unmodeled
  part, each named for what it is (never "Other").
- `src/lib/player/stats-premium.ts` `careerScoringNote()`: one note under the career table, reusing the
  Stats tab's existing `.scp-stp-note` info line, listing each affected season newest first, e.g.
  "FPTS also counts scoring with no column in the table: 2024 Passing 1 TD, 7 yds (+4.3); 2021 2-pt
  conversions 2 (+4.0)." No note when every row reconciles from its columns.
- `public/player.css`: `.scp-stp-scorenote` insets that line to the card padding (copy of the existing note
  style, no new look).
- No printed figure changed: FPTS, PPG, Finish, FAQ answers and the hub Season Stats block print the same
  numbers as before. Items 4+5 need no change.

## League-wide reconciliation (every player, every season with logs, 2009-2026)

Displayed career-row FPTS (rounded) vs. the arithmetic of the visible columns, 10,397 player-seasons
(QB/RB/WR/TE/K), tolerance 0.05:

| Mode | Before | After |
|---|---|---|
| `house` (deployed) | 2,088 fail | 0 fail |
| `provider` (rollback) | 4,292 fail | 0 fail |

Before, `house`, by cause (a row can have several): 2-pt conversions 1,010 rows; kicking with no columns
652 (all K rows that kick); return/fumble-recovery TD 225; non-QB passing 234; QB receiving 123; kicker
weeks without FG distances (provider total kept) 17. By position: K 652, WR 556, QB 453, RB 271, TE 156.
Under `provider` the extra ~2,200 rows are the provider's own events (pre-2022 -1 per fumble, forced-fumble /
special-teams credits); they now print as "Provider-scored events not in the stat line (+x)".

Limitation, labeled on the page: 17 kicker seasons have weeks whose field goals carry no distance, so the
house rule cannot score them; their kicking is printed as "Kicking without FG distances (provider total)".
Kicker rows are covered by the code, but Justin Tucker's Stats tab (checked) prints no career table, so
kickers are not expected to show the note today.
