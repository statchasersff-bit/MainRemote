## WEB-024: the failed stylesheet request

Divi 4.27.9 prints a footer script that adds its "late" dynamic CSS: `var file = [...]; ... link.href = file;`.
`file` is an array.

Live, 2026-11-24 (read-only curl):

- Pair pages and played game pages on 4825: `file` holds one URL (`.../et-cache/4825/et-divi-dynamic-tb-268-tb-269-4825-late.css`).
  The same file is ALSO enqueued as `divi-dynamic-late-css` with `?ver=` (Asset CleanUp preload), and the script's
  exact-href check misses the query string: **the file is downloaded twice on every matchup page**.
- A game URL the plugin answers with 404 (`template_redirect` -> `set_404()` after Divi has named page 4825's
  file; the 404 layout adds its own): `file` holds two URLs, and `link.href = file` requests
  `"...4825-late.css,https://.../tb-268-tb-269-late.css"`: **a broken request (404)**. Example:
  `/nfl/dallas-cowboys-vs-kansas-city-chiefs/2026-week-13/`.

Fix: `wordpress-plugin/statchasers-news/statchasers-divi-late-css.php`. On matchup requests (`sc_matchup`), the
footer is buffered and Divi's loader is swapped for one that walks the array: one `<link>` per distinct file, each
from its own URL, skipping any file already linked (query string ignored). Anything that is not that loader, or an
array that is not stylesheet URLs, passes through untouched. A footer buffer someone else leaves open makes it stand
down. Smoke tests in `tests/smoke.php` ("Divi late-CSS loader").

Browser check (Chromium, the live HTML served locally with stub CSS, cold load then warm reload):

| Page | Before | After |
|---|---|---|
| Game 404 | 1 x 200 (`...late.css?ver`) + **1 x 404** (`a.css,b.css`) | 2 x 200, one per file, no duplicate |
| Game page (GB-DET wk 7) | 2 x 200 for the same file (with and without `?ver`) | 1 x 200 |

Same on warm reloads.

Still needs the WordPress environment (not available here): upload the zip, then on a cache-cleared request check
the network panel of a played game page and a game 404 (one `late.css` request per file, no `,` URL) and confirm the
footer carries `data-sc-late-css`; confirm WP Rocket's cached copy has the rewritten script. The plugin version is
NOT bumped on this branch (1.10.59 here; WEB-001 already took 1.10.61): bump it in the release branch.
